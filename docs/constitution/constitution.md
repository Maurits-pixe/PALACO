# PALACO Constitution — Genesis Seed

## Foundational invariant

Governance may constrain execution; execution may never silently redefine governance.

## Authority ordering

```text
Authority → Validation → Execution → Evidence → Evolution
```

Execution requires explicit authority and validation. Runtime actions must
be attributable, verifiable and evidence producing. An evolution proposal
does not authorize execution or a constitutional amendment.

## Scope

This seed makes the GEN-A1 boundary explicit; it does not replace or edit
the imported [Constitution](PCS/Constitution.md),
[Authority Framework](PCS/Authority-Framework.md) or their provenance.
Constitutional amendments require the explicit review and authorization
process in [GOVERNANCE.md](../../GOVERNANCE.md).
No new subsystem is authorized before Foundation/Core consolidation is
verified. A policy document alone is not runtime enforcement evidence.
