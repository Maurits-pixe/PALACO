# PALACO.NL/COM Monetary Interface v0.1.0

PALACO.NL/COM is the public presentation and status layer. It does not itself grant monetary authority.

## Public surfaces
- payment methods
- M.C. / M.C.7 information and status
- wallet entry
- HOTSPOT discovery
- I.E.O. registry/proof
- transaction history
- terms, privacy, fees and redemption conditions
- status: DRAFT / PILOT / ACTIVE / SUSPENDED / REVOKED / ARCHIVED

## Product principle
PALACO remains free at its core. Optional monetary/commercial additions may have explicit prices or terms determined by HOOFDKANTOOR.

## VORM9EVING
The interface must remain low-threshold, accessible, calm and architecture-first. Monetary status, conditions and limitations must be visible before an action requiring authorization.

## Boundary
The public interface may request an operation; BOTERHAM and the constitutional authorization layer determine whether it can execute.
