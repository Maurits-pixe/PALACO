# VISITCARD-UX-001
## Human Introduction Experience v0.1

### Status
Draft v0.1

### UX objective
Make PALACO introduction understandable in one glance.

## Minimal user flow
1. **Discovery notice**: “PALACO found”
2. **Recognition view**: object type + origin + validity
3. **Meet decision**: user chooses to continue
4. **RIO entry**: conversation/interaction starts

## Copy principles
- plain-language introduction
- no protocol jargon by default
- explicit action labels (View, Meet, Connect)

## UX constraints
- avoid repeated/flooded prompts
- deduplicate nearby discovery events
- preserve calm-notification behavior
