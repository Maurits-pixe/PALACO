# PALACO-VISITCARD-001
## Digital Introduction Object v0.1

### Status
Draft v0.1

### Canonical statement
**A PALACO VisitCard is a constitutionally bounded digital introduction object for a person, Citadel, World, ELIXER, or other PALACO-recognized object type.**

### Purpose
VisitCard enables recognizable introduction before deeper interaction.

### Core fields (logical)
- Identity
- Object Type
- Introduction
- RIO Address / Endpoint
- Watermerk Reference
- Hologram Reference
- Provenance
- Validity (active/expired/revoked)
- Presentation hints
- Discovery methods

### Discovery methods
- BLE
- NFC
- QR
- RIO Link
- Web
- 5LEUTEL
- Wearable

### Lifecycle
- ACTIVE
- EXPIRED
- REVOKED

### Constitutional boundary
**VisitCard introduces; it does not authorize.**

### Required properties
- verifiable origin/provenance
- bounded disclosure controls
- explicit validity state
- compatibility with RIO handshake entry

### Compliance tags
- VISITCARD-INTRO-COMPLIANT
- VISITCARD-PROVENANCE-COMPLIANT
- VISITCARD-REVOKE-COMPLIANT
