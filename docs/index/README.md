This index provides the canonical entry points for PALACO Foundation standards, schemas, governance decisions, and compliance artifacts.

## Directory Guide
- `docs/standards/` → normative specifications
- `docs/schemas/` → machine-readable schemas
- `docs/decisions/` → architecture decision records (ADR)
- `docs/profiles/` → surface-specific implementation profiles
- `docs/compliance/` → controls and release checklists
- `docs/changelog/` → domain-specific change logs
- `docs/index/` → index and navigation files
