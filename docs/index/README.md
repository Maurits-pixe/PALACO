# PALACO Foundation Docs Index

## Purpose
This index provides the canonical entry points for PALACO Foundation standards, schemas, governance decisions, and compliance artifacts.

## Primary Domains
- **RIO** (cross-surface communication platform)
- **VisitCard** (digital introduction object + discovery carriers)

## Read Paths
- **RIO canonical path:** `INDEX-RIO.md`
- **VisitCard canonical path:** `INDEX-VISITCARD.md`

## Directory Guide
- `docs/standards/` → normative specifications
- `docs/schemas/` → machine-readable schemas
- `docs/decisions/` → architecture decision records (ADR)
- `docs/profiles/` → surface-specific implementation profiles
- `docs/compliance/` → controls and release checklists
- `docs/changelog/` → domain-specific change logs
- `docs/index/` → index and navigation files

## Document Metadata Requirement
Each normative document should contain:
- Status
- Version
- Last Updated (YYYY-MM-DD)
- Owner

## Constitutional Reminder
**Communication, discovery, and identity do not by themselves grant authority.**
